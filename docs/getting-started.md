# Getting Started with Crevisto

## 1. Sign up
Visit https://crevisto.com — 5 free credits, no credit card required.

## 2. Pick a tool
Browse 100+ AI image tools at https://crevisto.com/tools

## 3. Generate
Upload a photo or enter a description. Get results in seconds.

## CLI option
```sh
curl -fsSL https://crevisto.com/install.sh | sh
crevisto trial
crevisto generate linkedin-avatar --input photo=./me.jpg --output ./result.webp
```

## BYOK (unlimited)
```sh
crevisto set-key sk-or-v1-xxxxx
crevisto generate logo-maker --input description="A tech startup logo" --output ./logo.webp
```
